# NCCL functions that the front defines by hand (front_nccl.cpp): the
# communicators' lifecycle, which their records follow, and the unique ids,
# which a restart makes again; the operations, which translate the stream
# and count for the drain, and the group regions, which the drain waits
# for; ncclMemAlloc and ncclMemFree, through the front's allocator; and what
# a restart makes again on a communicator: buffer registrations, windows,
# PreMulSum operators, and its suspension; and the device API's host
# functions, after which a checkpoint stops, since the device addresses do
# not outlive a restart.  A name that ends in '?' is in newer NCCLs only.
# Not supported (they abort with their name): the device API's team
# functions, which NCCL's headers also declare for the device, and the
# barrier requirements that take a team; ncclCommGrow, ncclCommGetUniqueId
